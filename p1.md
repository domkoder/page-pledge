## 1. What PagePledge is

A Solana app that fights dropout in study and reading cohorts. Each participant stakes USDC into a per-cohort vault, answers an AI-graded comprehension check at each milestone, and gets their stake back if they keep up. Missed milestones forfeit part of the stake to participants who finished everything. The AI grades learning. The program (not the AI) decides who failed, using deterministic rules.

## 3. Protocol rules MockChain must enforce

Money: USDC with 6 decimals as integer base units (BigInt). No floats anywhere. Protocol fee = 200 bps of net forfeits, fixed by the protocol and not user-settable.

Cohort states: Open -> Active -> Settling -> Finalized. Joins only while Open. The creator starts the cohort (needs at least 2 participants). Active becomes Settling once now > last deadline + grace. Cohort fields: id (creator-supplied nonce), epoch (created_at), stake, milestoneCount M (2-10), maxParticipants (2-50), deadlines[i], grace period, contentHash, oracle pubkey, clusterId, programId.

Per-user, per-milestone rules (i = milestone index, all time checks use the simulated clock):

- Commit: allowed while now <= deadline[i]. Stores hash(answer) and a chain timestamp. A user may re-commit a new answer before the deadline if the milestone isn't passed (max 3 attempts); the latest commit is what the oracle must attest.
- Complete: requires a valid oracle attestation with score >= 75 that references that exact commit hash. Allowed only if commit timestamp <= deadline[i] AND now <= deadline[i] + grace. Each milestone can be completed once (bitmap), so replays do nothing.
- Milestone outcome after deadline[i] + grace: no commit = MISSED; committed but failed grade = MISSED; committed but never graded = NEUTRAL (no slash, no reward eligibility); passed = PASSED.
- settle_user: callable by ANYONE, once per user, only after the last milestone's window has closed. Computes the user's missed count. The caller earns a bounty = min(1% of that user's forfeit, 1 USDC), paid out of the forfeit at settle time. Duplicate settle is rejected.
- finalize: anyone, once every user is settled. Computes payouts.
- claim: each user once, only after Finalized.

Attestation: Ed25519 signature (tweetnacl) over a canonical, domain-separated byte payload: "PAGEPLEDGE_ATT_V1" || programId || clusterId || cohort || cohortEpoch || user || milestoneIdx || score || commitHash || expiresAt. MockChain rebuilds the payload itself from its own state and verifies the signature against the oracle key in the cohort config. It never trusts a payload from the client. Put this in one `verifyAttestation()` function so it can later be swapped for a transaction co-signer check.

Error codes (mirror program errors): WrongUser, WrongCohort, AttestationExpired, ScoreTooLow, AlreadyCompleted, SubmissionWindowClosed, NotCommitted, SettlementTooEarly, AlreadySettled, NotFinalized, AlreadyClaimed, BadSignature, CohortNotOpen, CohortFull.

## 4. Economics (pure functions in lib/economics.ts, unit-tested)

Definitions: S_i = stake, M = milestones, missed_i = missed count, eligible_i = all M milestones PASSED, B = total bounties paid at settle, phi = fee rate.

- Forfeit F_i = floor(S_i * missed_i / M). Net forfeit N_i = F_i - bounty_i.
- Liabilities U = sum(S_i) - B. Assets A = actual vault balance at finalize (deposits + simulated yield - lender loss - B).
- Yield Y = max(A - U, 0). Haircut h = min(1, A / U). If h < 1 then Y = 0.
- Fee = phi * sum(N_i). Pool = h * (1 - phi) * sum(N_i) + Y.
- payout_i = h * (S_i - F_i) + (eligible_i ? Pool * S_i / sum of S_j over eligible j : 0).
- If nobody is eligible: each user also gets back h * (1 - phi) * N_i, and Y goes to the treasury.
- Floor all divisions and send dust to the treasury.
- Invariant, asserted in code and shown in the UI: sum(payouts) + fee + dust = A.

Vitest cases: all finish; all fail; mixed with a NEUTRAL user; lender loss (h < 1); rounding dust; single finisher; max-size cohort; plus a randomized property test of the invariant.

Simulated yield: accrue at a configurable APR (default 5%) over simulated elapsed time, funded from a labeled "simulated yield reserve". Never present it as real yield. A "lender loss %" control reduces assets at finalize.
